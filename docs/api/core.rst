Core
====

Modules principaux
------------------

``hrneowave.core.project_manager``
   Creation, chargement et enumeration des projets et sessions.

``hrneowave.core.post_processor``
   Post-traitement des donnees acquises.

``hrneowave.core.export_manager``
   Brique utilitaire de sortie de donnees, encore secondaire par rapport au flux GUI valide.

``hrneowave.core.signal_bus``
   Support de signaux internes.

``hrneowave.core.config_manager``
   Gestion de configuration technique.

``hrneowave.core.calibration_certificate``
   Generation de certificats annexes.

Remarque
--------

Cette page decrit les modules encore presents et utiles. Elle ne pretend pas qu'ils sont tous exposes dans la navigation GUI actuelle.
